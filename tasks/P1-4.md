# P1-4: Virtual Marlin

## Goal
Software 'printer' that executes G-code like Marlin would at the level we care about: parses commands, tracks position/modes, enforces bed limits, models planner timing (use R5-1 simulator when available; until then a documented trapezoidal model), answers over a pty/serial-like interface with `ok`, buffer limits, and errors; and renders the executed trajectory to PNG/SVG with pen-down/up colouring.

## Acceptance
- Rejects/records violations: move outside bed, Z below configured minimum, heater command, unknown command (negative tests, each produces a distinct error code).
- Executes compiled output of P1-3 golden pages with zero violations and a rendered PNG; image opened and described.
- Time estimate unit-tested against hand-calculated trapezoid cases (3 cases documented with the arithmetic).
- Serial-like interface supports the line-number + checksum + resend protocol (`Resend: N`) tested with injected corruption.
- Runs headless in CI on all three OSes (no pty dependency on Windows: use an in-process transport behind the same interface).

## Anti-shortcut
- The simulator must not simply return 'ok' for everything. Every accepted command has an effect on state that a test asserts.

## Evidence
Violation test table, rendered PNG, timing cases.
