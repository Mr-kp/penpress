# P9-2: Cross-Platform Packaging, Virtual Print Driver, and Release v0.1.0

## Goal
Package PenPress into a standalone commercial product. Build cross-platform standalone binaries (Linux ELF, macOS `.app`/`.dmg`, Windows `.exe`), provide desktop entries and high-contrast graphite icons, create systemd user service templates, package an optional virtual print driver / CUPS backend (allowing users to "Print" directly from Word, LibreOffice, or browser to PenPress), and produce release artifacts for v0.1.0.

## Inputs / context to read first
- `BRIEF.md` (Product contract)
- `README.md` (Quickstart, architecture)
- Rule 3: Anti-Premature Stopping Protocol (Standalone executable, packaging, rollback guarantee)

## Deliverables
1. `scripts/package.py`: PyInstaller / standalone binary bundler for Linux, macOS, and Windows.
2. `packaging/cups/`: Optional Linux/macOS CUPS virtual backend script (`penpress-print`).
3. `packaging/desktop/`: `.desktop` file, Apple plist, and SVG/PNG minimalist icons.
4. `docs/user/quickstart.md`: Comprehensive user guide with screenshots and hardware assembly walkthrough.
5. `release/`: Multi-platform release manifest with SHA256 checksums.

## Acceptance
- Compiles and verifies standalone executable artifacts for Linux, macOS, and Windows.
- `penpress --version` in standalone binary outputs `v0.1.0`.
- Standalone binary launches `penpress serve` and handles document conversion without system Python installed.
- Virtual print driver receives test PDF postscript stream and enqueues job into PenPress queue.
- Negative test: Submitting an oversized > 50 MB print job to the driver rejects gracefully with clear spooler error message.

## Anti-shortcut
- Do not stop at a virtual python environment script; must generate installable binaries.

## Evidence
Binary build transcripts, release checksum manifest, virtual print spooler log.
