# P6-1: Path Optimization, Traveling Salesperson Sort, and Bed Mesh Z-Compensation

## Goal
Implement pen toolpath optimization to minimize airborne pen-lift travel time, sort strokes using 2-opt Euclidean Traveling Salesperson Problem (TSP) heuristics, merge collinear/tangent strokes, reverse direction when beneficial, and apply bilinear bilinear interpolation across Marlin bed levelling meshes (M420 / G29 bilinear grid).

## Inputs / context to read first
- `docs/developer/adr/0005-kinematics-physical-limits.md` (Pen lift latency, travel speeds)
- `src/penpress/plan/compiler.py`
- `src/penpress/core/primitives.py`

## Deliverables
1. `src/penpress/plan/optimizer.py`: Fast 2-opt / KD-tree stroke ordering minimizing non-drawing travel distance.
2. `src/penpress/plan/merger.py`: Merges adjacent collinear stroke endpoints within tolerance (<= 0.15 mm).
3. `src/penpress/plan/mesh_comp.py`: Bilinear Z-interpolation adjusting pen contact height across measured bed topography.
4. `tests/unit/plan/test_optimizer.py`: Benchmark measuring non-drawing travel distance reduction and Z-mesh accuracy.

## Acceptance
- `pytest tests/unit/plan/test_optimizer.py` passes 100%.
- Optimization reduces non-drawing pen-up travel distance by >= 35% compared to naive document order.
- Stroke reversal chooses shortest jump between end-of-stroke-A and start/end-of-stroke-B.
- Bed mesh compensation computes interpolated Z contact heights within +-0.01 mm of analytical plane.
- Negative test: Zero-length strokes or NaN coordinates raise `InvalidGeometryError` during pre-flight optimization checks.

## Anti-shortcut
- Do not invert unidirectional strokes if pen nib mechanics prohibit back-strokes (configurable `allow_stroke_flip`).

## Evidence
Before/after travel distance numbers in meters, travel path visualization, unit test report.
