# P1-3: G-code compiler

## Goal
Compile pages of strokes into safe Marlin G-code for a machine profile (TOML): bed limits, pen offset, Z-up/Z-write heights, feedrates, acceleration profile hooks, paper origin and rotation.

## Deliverables
`src/penpress/plan/` : `MachineProfile` loader with validation, compiler, preamble/postamble (heaters off `M104 S0 / M140 S0`, fans off `M107`, `G90`, `G21`, lift Z first, home policy), line numbers/checksums option, optional arc output off by default.

## Acceptance
- Property tests (Hypothesis) over random pages and profiles: every coordinate is inside the bed after offsets; Z never below `z_write_min`; every pen-down is followed by a pen-up before any travel move; no heater/fan-on commands are ever emitted; first motion command after start is a Z lift.
- Compilation of out-of-bounds content fails with a clear error unless explicit clamp is enabled (negative test).
- Invalid profiles (negative sizes, z_up < z_write) rejected (negative tests).
- Golden G-code test for 3 fixed pages (reviewed by human diff).
- Compiler throughput >= 20k segments/s on T0.

## Anti-shortcut
- Do not hardcode Ender dimensions inside the compiler; they live in the profile. Do not emit Z moves below zero ever.

## Evidence
Hypothesis stats, golden file diff, throughput number.
