# P5-1: Document Ingest Pipeline and Structured Block Parser

## Goal
Promote and productionize the R4-1 document ingest engine into `src/penpress/ingest/`. Parses PDF and Markdown+LaTeX files into structured blocks (Titles, Headings, Paragraphs, Equations, Tables, Vector Figures), extracts vector path polylines, executes Tesseract OCR fallback for scanned pages, sorts reading order across multiple columns, and enforces hostile PDF defenses.

## Inputs / context to read first
- `docs/developer/adr/0004-pdf-ingest.md` (Tiered Fast Path, hostile limits)
- `research/R4-1/ingest/engine.py`
- `research/R4-1/ingest/schema.py`

## Deliverables
1. `src/penpress/ingest/engine.py`: Production `DocumentIngestEngine` supporting PDF and Markdown files.
2. `src/penpress/ingest/markdown_parser.py`: Markdown parser converting headings, bullet lists, bold text, and math equations into document blocks.
3. `src/penpress/ingest/schema.py`: Versioned JSON document schema.
4. `tests/unit/ingest/test_ingest.py`: Full ingest test suite including multi-column layouts and hostile files.

## Acceptance
- `pytest tests/unit/ingest/test_ingest.py` passes 100%.
- Digital single/two-column PDF extraction throughput >= 15 pages / second on CPU.
- Monotonic reading order correctness >= 95% on multi-column benchmarks.
- Vector drawings in figures preserved as float coordinate polylines without rasterisation.
- Negative test: Corrupted/malformed PDFs caught with structured `IngestError` without crashing.

## Anti-shortcut
- Do not import PyMuPDF or any AGPL library.
- Do not silently drop unrecognized content.

## Evidence
Test execution logs, document JSON export, benchmark timing numbers.
