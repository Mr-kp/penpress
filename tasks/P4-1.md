# P4-1: Mathematical Formula Handwriting Layout and Symbol Synthesis Engine

## Goal
Implement the end-to-end mathematical formula synthesis engine based on ADR-0002. Compiles LaTeX expressions into vector layout trees using MathJax/KaTeX, resolves glyphs through a 3-tier fallback chain (user profile bank -> organic Hershey math glyphs -> wobbly vector rules), synthesizes stretchy delimiters/radicals/fractions, and compiles multi-line matrix structures into plottable stroke primitives.

## Inputs / context to read first
- `docs/developer/adr/0002-equations-synthesis.md` (Node MathJax bridge, 3-tier fallback chain)
- `research/R2-1/math_layout/engine.py` and `research/R2-1/math_layout/bridge.js`
- `tests/fixtures/equations.jsonl` (125 benchmark equations)

## Deliverables
1. `src/penpress/core/math_engine.py`: Python wrapper and Node bridge for MathJax SVG layout.
2. `src/penpress/core/math_symbols.py`: Stretchy brackets, fraction bars, square root radicals, summation/integral symbols, and Greek letter vector fonts.
3. `tests/unit/core/test_math.py`: Automated tests across all difficulty levels of `equations.jsonl`.

## Acceptance
- `pytest tests/unit/core/test_math.py` passes 100%.
- 100.0% compilation success across all 125 equations in `tests/fixtures/equations.jsonl`.
- Throughput: >= 20 equations / second on CPU.
- Preserves relative scale: sub/superscripts rendered at 65-75% of parent baseline font size.
- Negative test: Malformed or unparseable LaTeX (e.g. `\frac{1}{` or `\sqrt[`) raises explicit `LaTeXParseError` without Node subprocess crash.

## Anti-shortcut
- Do not rasterise equations to PNG and vectorize via potrace; must layout directly in vector space.
