# P5-2: Page Composer and Layout Typesetter

## Goal
Implement the page layout composer that fits structured assignment blocks onto physical paper sizes (A5 single-pass primary per ADR-0005, A4 indexed/multi-pass). Manages line wraps, paragraph justification, section indentation, margin constraints, ruled line alignment (grid/lined paper), and obstacle keep-out buffer clipping.

## Inputs / context to read first
- `docs/developer/adr/0005-kinematics-physical-limits.md` (A5 primary 148x210 mm, bed margins, clip keepouts)
- `src/penpress/ingest/schema.py`
- `src/penpress/core/primitives.py`

## Deliverables
1. `src/penpress/layout/composer.py`: Multi-page layout composer supporting A5/A4 presets, customizable margins (top/bottom/left/right), line heights (7 mm / 8 mm college ruled), and pagination.
2. `src/penpress/layout/keepout.py`: Clips or offsets blocks away from physical binder clip keep-out polygons.
3. `tests/unit/layout/test_composer.py`: Tests for pagination, overflow handling, and ruled alignment.

## Acceptance
- `pytest tests/unit/layout/test_composer.py` passes 100%.
- Generates valid multi-page document fitting 1000-word essay with equations onto A5 sheets.
- Text baselines strictly align with simulated 7 mm ruled notebook guidelines within +-0.2 mm.
- Zero strokes intersect the 5 mm expanded clip keep-out zone.
- Negative test: A single block larger than page dimensions raises `LayoutOverflowError` with actionable pagination suggestions.

## Anti-shortcut
- Do not let text overflow past physical bed travel limits (220 x 220 mm).

## Evidence
Test logs, rendered multi-page SVG/PNG layouts, baseline alignment measurements.
