# P10-1: Unified CLI Pipeline for PDF, Markdown+LaTeX, and Standalone Math Bundling

## Goal
Connect the full production pipeline (`DocumentIngestEngine` -> `PageComposer` -> `OrganicHumanizer` + `MathEngine` -> `ToolpathOptimizer` -> `GcodeCompiler` -> `MarlinSimulator`) into the CLI and standalone binary so users can drop in any `.pdf`, `.md`, or `.txt` assignment from the command line and get multi-page G-code, simulated toolpath PNG/SVG renders, and telemetry.

## Inputs / context to read first
- `FLASH_HANDOFF.md`
- `src/penpress/__main__.py`
- `src/penpress/ingest/markdown_parser.py`
- `src/penpress/core/math_engine.py`
- `scripts/package.py`

## Deliverables
1. Fix `UnboundLocalError` for `h = 35.0` in single-line `$$...$$` display math in `src/penpress/ingest/markdown_parser.py`.
2. Ensure `src/penpress/core/math_engine.py` resolves `mathjax_layout.js` cleanly both in repo checkout and PyInstaller `sys._MEIPASS` bundle (and update `scripts/package.py` to bundle `research/R2-1/mathjax_layout.js` and `research/R2-1/node_modules` or provide a deterministic vector fallback when `node_modules` is unavailable).
3. Add `penpress render <file>` subcommand in `src/penpress/__main__.py` supporting `.pdf`, `.md`, and `.txt` inputs with `--paper A5|A4`, `--profile`, `--out`, and `--optimize`, outputting per-page `.gcode`, `.png`, and `.svg` files plus summary JSON/stdout telemetry. Also fix `penpress` with no arguments to print help instead of `"no commands available yet"`.
4. Add unit/integration tests in `tests/unit/plan/test_cli_render.py` testing `penpress render` on both a `.md` file with `$$...$$` equations and a multi-page `.pdf` fixture with equations and vector figures.

## Acceptance
- `uv run pytest tests/unit/plan/test_cli_render.py` passes 100%.
- `uv run penpress render tests/fixtures/pdfs/mixed_math_assignment.pdf --out /tmp/pdf_out` succeeds (exit code 0) and generates valid `.gcode`, `.png`, and `.svg` with 0 simulator violations.
- `uv run penpress render` on a Markdown file starting with a single-line `$$\frac{a}{b} = c$$` equation succeeds without `UnboundLocalError` and renders fraction rules + math strokes.
- Negative test: `uv run penpress render nonexistent.pdf` or an unsupported `.exe` extension exits non-zero with a clear error message.

## Anti-shortcut
- Do not bypass `DocumentIngestEngine`, `PageComposer`, `MathEngine`, or `ToolpathOptimizer` in `penpress render`.

CLI command outputs, generated simulator PNGs from PDF and Markdown inputs inspected via `view_file`, test results in `docs/evidence/P10-1/EVIDENCE.md`.
