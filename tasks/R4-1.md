# R4-1: PDF ingest research spike

## Goal
Choose the local pipeline that converts any assignment PDF (digital or scanned, one or two columns, with equations, tables and figures) into a structured document: headings, paragraphs, lists, tables, **equations as LaTeX**, **figures as vector paths or images** with captions and positions.

## Candidates (verify licences first: see landscape doc)
Docling (MIT); pdfminer.six / pypdfium2 for text and vector paths; pix2tex / pix2text for equation images; PaddleOCR (Apache) and Tesseract for scans; Marker (weights restricted: opt-in only); MinerU (read LICENSE.md; subprocess only if usable); LLM-based conversion as an **opt-in** plugin, measure only. PyMuPDF is AGPL: not allowed in the shipped product.

## Deliverables
1. `docs/developer/research/R4-1.md`: evidence log.
2. `research/R4-1/` runnable pipeline prototype: `pdf -> document.json` (block types, reading order, bbox, text, latex, figure refs) and a viewer that overlays detected blocks on pages.
3. Benchmark on R0-1 PDF corpus (generated PDFs have ground truth; real PDFs are scored by sampled manual audit).
4. Figure handling study: extracting vector paths (lines, curves, text-in-figure) vs raster tracing (skeleton-tracing, potrace-class); which figures can become pen strokes cleanly.
5. Equation handling study: detection, crop, image-to-LaTeX accuracy, CPU speed.
6. ADR `docs/developer/adr/0004-pdf-ingest.md`.

## Metrics
| Metric | Target |
|---|---|
| Reading-order correctness (generated corpus) | >= 95% of blocks in correct order |
| Block type F1 (heading/paragraph/list/table/equation/figure) | >= 0.90 |
| Text accuracy (normalised CER) | <= 2% for digital PDFs, <= 6% for scans |
| Equation LaTeX normalised match | >= 80% on difficulty 1-2 |
| Vector figure extraction | >= 90% of vector figures yield strokes preserving topology (audit) |
| Speed on T0 (10-page PDF) | <= 3 min, with progress reporting |
| Memory | fits in 3 GB or runs in an isolated subprocess with a documented limit |
| Failure behaviour | any block that fails becomes an explicit placeholder block with the original crop, never silent loss |

## Acceptance
- Benchmark reproducible from README within +-5%.
- ADR accepted; licence verdicts for every dependency; fallback tiering (fast path, accurate path, opt-in LLM path) described with triggers.
- Overlay images for 6 PDFs opened and described, flaws included.
- Proven safe handling of hostile PDFs: oversized pages, encrypted, malformed, huge embedded images (resource limits, no crash, clear error).

## Anti-shortcut
- Do not score only on the PDFs you tuned on.
- Do not use PyMuPDF or any AGPL/unclear component in the proposed shipped path.
- Do not drop content silently; unrecognised content must surface.

Commands, benchmark table, overlay descriptions, hostile-PDF results, ADR link.
