# P0-3: CI

## Goal
GitHub Actions runs the full gate on all three OSes for every push.

## Acceptance
- `gh run list --limit 1` shows success; all three matrix jobs green.
- A deliberate bad commit on a branch (an added TODO in src) makes the gate fail in CI. Evidence: failing run URL; branch deleted after.

## Anti-shortcut
- Do not mark CI jobs continue-on-error. Do not disable Windows/macOS.
