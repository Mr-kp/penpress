# P1-5: First vertical slice

## Goal
`penpress render-text FILE.txt --profile ender3pro --out out/` produces G-code, executes it in the simulator and writes a PNG, then OCR reads it back.

## Acceptance
- CLI command exists and is documented in README with real output.
- Input: a 120-word text. OCR round-trip CER <= 8% on the simulator's rendered PNG.
- Simulator reports 0 violations; total pen lifts and estimated time printed.
- A deliberately oversize text returns a clear error or paginates (documented choice, tested).
- CI runs this e2e on all three OSes (Tesseract install step added in CI).

## Anti-shortcut
- The OCR must read the simulator's render of the G-code, not the original font render.

## Evidence
Command transcript, PNG, OCR output vs input diff, CI run URL.
