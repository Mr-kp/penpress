# P8-1: Dual-Mode Calibration Wizard

## Goal
Implement the end-to-end printer calibration system providing two operating paths:
1. **Camera Automated Mode (per ADR-0003):** Smartphone / webcam video feed detects paper corners, computes RANSAC homography, isolates binder clip keep-out polygons, and verifies alignment.
2. **Manual Tactile Jog Mode:** Step-by-step interactive wizard that jogs the toolhead to 3 paper corners, prompts paper-drag height check, and records coordinates when cameras are unavailable or lighting is deficient.

## Inputs / context to read first
- `docs/developer/adr/0003-vision-calibration.md` (Multi-scale contour, RANSAC homography, 0.33 mm mean error)
- `research/R3-1/vision/engine.py` (Vision calibration engine)
- `docs/user/hardware-test-protocol.md` (Physical Ender 3 Pro test protocol)

## Deliverables
1. `src/penpress/vision/calibrator.py`: Automated vision calibration engine with clip detection and confidence gating.
2. `src/penpress/vision/manual_wizard.py`: Interactive manual jogging calibration state machine.
3. `src/penpress/vision/bed_model.py`: Immutable bed coordinate mapping and transform manager.
4. `tests/unit/vision/test_calibrator.py`: Tests covering camera calibration, negative vision fixtures, and manual wizard state transitions.

## Acceptance
- `pytest tests/unit/vision/test_calibrator.py` passes 100%.
- Paper corner localization error <= 0.50 mm on `tests/fixtures/bed_scene_topdown_bright.png`.
- Clip keepout buffer expanded by >= 5.0 mm in physical bed coordinates.
- 0.0% false accept rate on negative fixtures (`negative_glare_corner.png`, `negative_blank_page.png`).
- Negative vision conditions (`FRAME_TOO_DARK`, `SEVERE_GLARE_OCCLUSION`) cleanly transition the session to manual jog mode without error dialogs.

## Anti-shortcut
- Do not make the camera mandatory; manual jog mode must be 100% capable of completing calibration independently.

## Evidence
Corner accuracy measurements, test logs, manual wizard state machine sequence test output.
