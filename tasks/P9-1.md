# P9-1: Minimalist Dark Studio UI and REST API with Live Toolpath Telemetry

## Goal
Build the unified Web/Desktop application interface for PenPress adhering strictly to Linear / Apple macOS minimalist dark graphite aesthetic standards (`#0d0e12` obsidian background, `#141722` cards, `#212638` subtle borders, `#f8fafc` primary text). Provides 5 integrated views:
1. **Document Studio:** Live Markdown/LaTeX editor with structured block preview and ruled page composer.
2. **Profile Studio:** Interactive handwriting profile manager and canvas capture.
3. **Calibration Wizard:** Dual-mode camera/jog alignment view with clip keepout overlays.
4. **Plot Monitor:** Live toolpath simulation, progress scrubber, feedrate override, pause/cancel controls, and serial telemetry.
5. **Settings:** Machine profile limits, baud rate, and safety parameters.

## Inputs / context to read first
- Rule 6: Minimalist Design & Visual Polish Standard (Dark graphite, zero kindergarten candy colors, emoji restraint, no clipped text)
- Rule 1: Private Tailscale network security (bind strictly to `127.0.0.1` or `100.121.213.19`, DNS rebinding defenses)
- `src/penpress/plan/sim.py` (Toolpath visualizer)

## Deliverables
1. `src/penpress/api/server.py`: FastAPI server binding strictly to loopback or private Tailscale IP with security headers.
2. `web/`: Modern minimalist HTML5/CSS3/TS frontend (Document Studio, Profile Studio, Calibration, Plot Monitor).
3. `tests/unit/api/test_server.py`: API endpoint tests, DNS rebinding checks, and security tests.
4. `docs/screenshots/ui/`: High-resolution headless browser screenshots of all 5 UI views.

## Acceptance
- `pytest tests/unit/api/test_server.py` passes 100%.
- Server enforces private binding: Reject external Host headers (allow only loopback, `100.121.213.19`, `*.ts.net`).
- 0 console errors or JavaScript exceptions during browser test suite run.
- Automated headless browser takes 5 view screenshots saved into `docs/screenshots/ui/` and inspected via `view_file`.
- Interactive toolpath preview renders 100,000 segments with 60 FPS Canvas/WebGL performance.
- Negative test: External public IP or untrusted Host header requests return HTTP 403 Forbidden.

## Anti-shortcut
- Do not use bright primary colors (red/green/blue blocks) or emoji icons.
- Do not leave empty black terminal boxes; display elegant centered status cards.

Inspected screenshots for all 5 tabs in `docs/screenshots/ui/`, API security test transcript, browser console log.
