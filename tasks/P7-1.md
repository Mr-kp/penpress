# P7-1: Robust Serial Driver, Line Checksum Protocol, and Hardware Recovery Engine

## Goal
Implement the serial communication manager for Marlin firmware over USB/UART (`/dev/ttyUSB*` / `COM*`). Manages baud rate auto-negotiation (115200/250000), line-numbered command streaming (`N<num> <cmd> *<checksum>`), `ok` acknowledgment parsing, `Resend:` line recovery, non-blocking queueing, pause/resume/cancel semantics, and persistent resume-after-disconnect state recording.

## Inputs / context to read first
- `src/penpress/plan/sim.py` (Marlin serial protocol and checksum implementation)
- `src/penpress/plan/compiler.py` (G-code output format)
- `docs/developer/adr/0005-kinematics-physical-limits.md`

## Deliverables
1. `src/penpress/machine/serial_driver.py`: Async/threaded serial port reader and writer with Marlin flow control.
2. `src/penpress/machine/state_tracker.py`: Real-time machine coordinates, buffer depth, current layer/stroke tracking.
3. `src/penpress/machine/recovery.py`: Persists execution state to local disk (`.print_state.json`) allowing stroke-level resume after disconnection or power glitch.
4. `tests/unit/machine/test_serial.py`: Comprehensive test suite using virtual loopback serial pty / mock printer.

## Acceptance
- `pytest tests/unit/machine/test_serial.py` passes 100%.
- Successfully transmits 10,000 G-code commands with line numbering and checksums through virtual Marlin simulator.
- Recovers from simulated checksum transmission corruptions via Marlin `Resend: N` protocol without dropped moves.
- Disconnect recovery test: Simulating un-plugging mid-job preserves the exact last completed stroke ID; re-connecting resumes cleanly from stroke $N+1$ without scratching paper.
- Negative test: Communication timeout (> 5.0 s with no `ok`) cleanly pauses execution, lifts Z axis, and emits a warning event.

## Anti-shortcut
- Do not dump G-code blindly to serial without waiting for `ok` / buffer management.

## Evidence
Virtual serial test transcript, checksum error injection log, recovery state file inspection.
