# P3-1: Organic Humanizer Engine

## Goal
Implement the organic humanizer engine that transforms mechanical font/glyph sequences into natural, authentic human handwriting. Implements multi-variant glyph indexing, micro-jitter, baseline sinusoidal wander, word-level slant drift, ink-dynamics velocity modulation, and bold simulation via multi-pass toolpaths.

## Inputs / context to read first
- `docs/developer/adr/0001-handwriting-cloning.md` (Section 3: Organic Humanizer specifications)
- `research/R1-1/cloning/bank.py` (`OrganicHumanizer`)
- `src/penpress/core/hershey.py`

## Deliverables
1. `src/penpress/synth/humanizer.py`: Full implementation of baseline wander ($\sigma=0.06$ mm), slant shear ($\mu=0, \sigma=2.5^\circ$), spacing jitter ($\sigma=0.15$ mm), and micro-wobble Perlin noise.
2. `src/penpress/synth/variant.py`: Anti-repetition variant selection avoiding consecutive duplicate glyphs.
3. `src/penpress/synth/dynamics.py`: Pen feedrate modulation based on stroke curvature and simulated nib pressure.
4. `tests/unit/synth/test_humanizer.py`: Statistical verification of jitter distributions and OCR round-trip.

## Acceptance
- `pytest tests/unit/synth/test_humanizer.py` passes 100%.
- Generates 100-word paragraph with zero identical glyph instances when >= 2 variants exist.
- Statistical tests verify baseline jitter adheres to Gaussian distribution $N(0, \sigma^2)$ with $\sigma \in [0.04, 0.08]$ mm.
- Tesseract OCR CER on humanized synthetic page is <= 1.0% (legibility guaranteed).
- Negative test: Zero jitter parameter (`jitter=0`) produces deterministic straight baseline and raises no exceptions.

## Anti-shortcut
- Do not apply uniform pseudo-random noise; must use smooth low-frequency drift (Perlin or cubic splines) to avoid jagged artifacts.

## Evidence
Histogram plots / stats in evidence, rendered PNG screenshot, OCR CER report.
