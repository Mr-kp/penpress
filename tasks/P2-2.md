# P2-2: Interactive Canvas and Tablet Stroke Capture Studio

## Goal
Implement the direct online stroke capture studio for touchscreens, Apple Pencil, and drawing tablets. Captures native Bezier/timestamped stroke sequences, computes legibility and completeness metrics, builds multi-variant glyph banks, and runs 100% offline with zero external egress.

## Inputs / context to read first
- `docs/developer/adr/0001-handwriting-cloning.md` (2-Tier UX Proposal: instant 60-second canvas tier)
- `src/penpress/profile/models.py`
- `src/penpress/core/primitives.py`

## Deliverables
1. `src/penpress/profile/canvas_capture.py`: Normalizes online pointer events (x, y, pressure, time) into `Stroke` primitives with velocity tracking.
2. `src/penpress/profile/quality.py`: Evaluates profile completeness, average stroke smoothness, and glyph coverage (A-Z, a-z, 0-9, common punctuation).
3. `tests/unit/profile/test_canvas.py`: Automated tests for online stroke capture and completeness scoring.

## Acceptance
- `pytest tests/unit/profile/test_canvas.py` passes 100%.
- Captures multi-stroke characters (e.g. 'E', 'A', 't', 'i') with correct stroke separation.
- Completeness score returns 100% when all alphanumeric glyphs have >= 1 variant.
- Negative test: Empty or single-dot scribbles fail quality gating with `QualityThresholdError`.
- Zero-egress test: Network socket audit during profile creation verifies 0 outbound network calls.

## Anti-shortcut
- Do not interpolate artificial intermediate strokes if input timestamps are missing.
- Do not flatten multi-stroke glyphs into a single continuous polyline.

## Evidence
Test outputs, JSON profile sample with online strokes, quality report metric table.
