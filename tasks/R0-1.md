# R0-1: Synthetic fixture factory

## Goal
Every later card needs realistic inputs and ground truth without owning a printer, a camera, or the user's handwriting yet. Build a **deterministic, seeded generator** plus a small committed fixture set, and a manifest recording the origin and licence of every file. This is the "simulate pictures, generate them or take them from the internet" requirement.

## Inputs / context to read first
`BRIEF.md`, `docs/developer/research/verified-landscape.md`, `docs/developer/compute.md`, `AGENTS.md` section 2.

## Deliverables
Code in `research/R0-1/fixturegen/` (runnable with `uv run python -m fixturegen ...`), outputs in `tests/fixtures/` (committed, **total size <= 8 MB**; larger sets regenerate on demand into git-ignored `research/R0-1/data/`), manifest `tests/fixtures/MANIFEST.md`.

1. **Handwriting sample sheets.** Printable A4 sample sheet template (grid cells for a-z, A-Z, 0-9, punctuation, math symbols, a pangram line, 3 sentences, 10 repeated "e"/"a"/"t" for variation). Rendered "filled in" using >= 4 **OFL-licensed** handwriting fonts (e.g. Caveat, Homemade Apple, Reenie Beanie, Shadows Into Light: verify each licence file) with per-cell jitter in slant, size, baseline. Then photographed-effects: rotation +-6 deg, perspective, vignette/shadow gradient, paper texture, gaussian + jpeg noise, low light, motion blur. Ground truth JSON: page corners, cell boxes, character labels.
2. **Online ground truth for stroke recovery.** Use a permissive single-stroke font (Hershey, public domain) to produce true pen trajectories, rasterise with variable pen width and ink-bleed to simulate pen strokes, so stroke-recovery algorithms can be scored against the real trajectory.
3. **Printer-bed scenes.** Procedural top-down and oblique (15-40 deg) camera renders of an Ender-3-like bed (dark PEI plate texture, 235x235 mm), a sheet of paper (A5 and A4-half) at random pose, 0-4 binder clips and tape strips on edges, optional ArUco/AprilTag sheet, gantry shadows, glare, lens distortion (barrel), 5 lighting presets. Ground truth: paper corners in px and bed mm, clip polygons, homography, camera intrinsics.
4. **Internet images (optional realism set).** >= 25 real photos of paper on desks / printer beds from sources with clear permissive licences (Wikimedia Commons CC0/CC-BY/PD, Unsplash/Pexels licence). Record URL, author, licence, retrieval date in the manifest. Hand-annotate paper-corner quads for >= 15 (provide a tiny annotation tool, output JSON).
5. **Equation corpus.** >= 120 LaTeX strings in `tests/fixtures/equations.jsonl` across categories: arithmetic, fractions, nested fractions, roots, exponents/indices, sums/integrals with limits, matrices, piecewise, trig/log, Greek, vectors/hats, chemistry (`\ce`-style), units. Each with a category tag and difficulty 1-3. (Write them yourself: no copyright problem.)
6. **PDF corpus.** >= 12 PDFs: 8 generated from LaTeX or Markdown by us (problem sets with equations, tables, figures, two-column, headings, lists), 4 real open-licensed (arXiv CC-BY or OpenStax CC-BY) with licence recorded. Ground-truth structure (`.json`: block types and text) for the generated ones.

## Acceptance
- `uv run python -m fixturegen all --seed 1234` run twice produces **byte-identical** files (sha256 compared; print both).
- `tests/fixtures/` <= 8 MB (`du -sh`), MANIFEST lists every file with origin + licence, no file with an unknown licence.
- Unit tests: each generator has tests for ground-truth consistency (e.g. projecting ground-truth bed corners with the stored homography lands within 0.5 px of the rendered paper corners; rendered cell boxes contain ink).
- Visual contact sheets `docs/evidence/R0-1/contact-*.png` for each fixture family; **you opened and described them**. At least 3 distinct looks per family.
- Negative fixtures exist: sheet with missing corner, paper not in frame, glare covering a corner, blank page.

## Anti-shortcut
- No reusing one image with trivial brightness changes as "variety".
- No ground truth computed by the same code the later cards will test (derive GT from the generator's own parameters, not from detection).
- Do not scrape sites with restrictive licences. If a licence is unclear, exclude the file.
- Do not commit anything with unclear licence "temporarily".

## Evidence
Commands run, sha256 of two generations, contact sheet paths with descriptions, size, manifest excerpt.
