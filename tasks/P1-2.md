# P1-2: Single-stroke fallback typography

## Goal
Clean, legible fallback text as strokes: needed before handwriting cloning exists, and as the fallback chain's last tier.

## Deliverables
Vendored Hershey data (public domain; record provenance in `docs/developer/licenses.md`), loader to `Stroke`s, text layout of one line with kerning and baseline, coverage for ASCII, Greek letters, common math symbols (+ - = < > <= >= != approx times div partial nabla infty sum prod int sqrt, arrows, sub/superscript digits).

## Acceptance
- Coverage report prints missing glyphs; ASCII printable = 100%, Greek = 100%, listed math symbols = 100%.
- Rendering test: render 'The quick brown fox jumps over the lazy dog 0123456789' to PNG and OCR with Tesseract: CER <= 5%. (Tesseract is a subprocess in tests only.)
- Unknown character handling returns an explicit `MissingGlyph` result, never a silent blank.
- Image opened and described in evidence.

## Anti-shortcut
- Do not hand-draw glyphs. Do not embed the font as a giant untested string; load from a data file with a checksum test.

## Evidence
Coverage table, OCR CER, PNG path + description.
