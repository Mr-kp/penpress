# P2-1: Profile Generator and Sample Sheet Ingestion Engine

## Goal
Implement the production sample sheet generator (PDF with ArUco/fiducial markers and prompt grids) and rectification pipeline. Ingest photographed/scanned sample sheets, rectify perspective, isolate cell bounding boxes, and extract clean stroke polylines into a versioned user profile adhering to ADR-0001.

## Inputs / context to read first
- `docs/developer/adr/0001-handwriting-cloning.md` (Glyph Bank standard, Chamfer threshold <= 2.0 px)
- `research/R1-1/cloning/bank.py` and `research/R1-1/cloning/stroke_recovery.py`
- `src/penpress/core/primitives.py`

## Deliverables
1. `src/penpress/profile/sheet_gen.py`: Generates printable A4/Letter calibration sheets with corner fiducials and letter/number grids.
2. `src/penpress/profile/sheet_ingest.py`: Rectifies captured photo/scan, locates cells, crops glyph images.
3. `src/penpress/profile/models.py`: Immutable `HandwritingProfile` with versioned schema, serialization, and export/import.
4. `tests/unit/profile/test_sheet.py`: Verification on synthetic sample sheets.

## Acceptance
- `pytest tests/unit/profile/test_sheet.py` passes 100%.
- Generates valid PDF printable sheet with >= 52 alphabet cells and fiducial markers.
- Ingestion achieves >= 95% cell localization accuracy on `tests/fixtures/sample_sheet_caveat.png`.
- Negative test: Rotated or corrupted sheet with missing fiducials raises explicit `SheetAlignmentError`.
- Recovered stroke polylines achieve mean Chamfer distance <= 2.2 px against ground truth `tests/fixtures/stroke_recovery_sample.json`.

## Anti-shortcut
- Do not hardcode cell grid pixel offsets; must detect fiducials dynamically.
- Do not discard stroke topological order.

## Evidence
Commands, Chamfer distance metric table on sample sheets, exported profile JSON.
