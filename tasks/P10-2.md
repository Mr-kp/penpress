# P10-2: End-to-End Interactive Web Studio UI Overhaul and REST API Wiring

## Goal
Overhaul `web/index.html`, `web/static/style.css`, `web/static/app.js`, and `src/penpress/api/server.py` to eliminate the low-effort "vibecoded slop" mockup and deliver a genuine, high-density, precision desktop/web CAD studio inspired by **Linear, Raycast, and Bambu Studio / Figma**, with 100% interactive end-to-end wiring across all 5 views.

## Inputs / context to read first
- `FLASH_HANDOFF.md` (Read Priority 1 Mandatory Design System & Layout Architecture!)
- Invoke the `modern-web-guidance` skill (`SKILL.md`) before writing HTML/CSS/JS.
- Rule 6: Minimalist Design & Visual Polish Standard (Dark graphite `#0b0c0e`/`#111318`/`#151821`, `tabular-nums`, crisp SVG icons, zero emojis, zero Bootstrap `#2563eb` candy buttons, zero giant empty black boxes).
- `src/penpress/api/server.py`

## Deliverables
1. **REST API (`src/penpress/api/server.py`)**:
   - Enhance `POST /api/document/compose` (and add humanizer parameter support: `baseline_wander_mm`, `slant_deg`, `spacing_jitter_mm`, `wobble_mm`) to run the full pipeline (`DocumentIngestEngine` -> `PageComposer` -> `ToolpathOptimizer` -> `GcodeCompiler` -> `MarlinSimulator`) and return: page dimensions, parsed block outline list (`block_id`, `block_type`, `text` snippet), actual page stroke polylines (`[[[x,y], ...], ...]`), compiled G-code string (and preview lines), simulator segments (with `pen_contact` boolean), and telemetry (`total_strokes`, `pen_lifts`, `travel_distance_mm`, `draw_distance_mm`, `estimated_duration_s`).
   - Add `POST /api/document/upload` accepting `.pdf` or `.md` uploads (up to 50 MB, sanitized), running full ingest + composition, and returning the complete render payload.
   - Add Profile Studio endpoints: `POST /api/profile/glyph` (ingests online pointer strokes via `CanvasStrokeSession`, updates active `HandwritingProfile`, and returns real `ProfileQualityScorer` metrics + character bank coverage list) and `GET /api/profile/sample-sheet.pdf` (returns downloadable calibration PDF generated by `generate_sample_sheet`).
   - Add Calibration & Settings endpoints: `POST /api/calibration/camera` (runs `CameraCalibrator` on synthetic/uploaded bed image and returns paper quad corners + clip keepout polygons in bed mm) and `POST /api/settings` (validates and persists updated machine profile settings).
2. **Craft UI & Frontend Architecture (`web/index.html`, `web/static/style.css`, `web/static/app.js`)**:
   - **Global Shell**:
     - Top command bar (44px) with active document badge, paper preset switcher (`A5 148×210mm` / `A4 210×297mm`), live job summary pill (`1,262 strokes · 3m 21s`), and primary actions.
     - Left navigation rail (200px) with crisp 1.5px stroke inline SVG icons, keyboard shortcut badges (`⌘1`–`⌘5`), and hardware status footer.
     - High-contrast neutral/graphite buttons (`#f8fafc` primary button with `#0b0c0e` text, subtle `1px solid rgba(255,255,255,0.08)` secondary buttons)—**remove the `#2563eb` Bootstrap blue**.
   - **1. Document Studio**:
     - Left pane: Compact PDF/Markdown drag-and-drop upload bar + monospace Markdown/LaTeX editor with quick-insert toolbar (`+ Equation`, `+ Physics Sample`, `+ Upload PDF/MD`) + live **Parsed Document Block Tree** at the bottom showing extracted blocks (`TITLE`, `HEADING`, `PARAGRAPH`, `EQUATION`).
     - Right pane: Full-bleed **Physical Paper CAD Viewport** (`<canvas>` with high-DPI `devicePixelRatio` scaling, top/left millimetre rulers, 7mm ruled lines, red margin line, corner binder-clip keepout overlays) rendering the **actual vector handwriting and MathJax strokes** returned by `/api/document/compose`. Bottom viewport bar with layer toggles (`Ink`, `Travel`, `Grid`, `Keepouts`), page switcher, and `Export G-code` / `Open in Plot Monitor` buttons.
   - **2. Profile Studio**:
     - Left pane: **62-Character Glyph Bank Grid** (`A–Z`, `a–z`, `0–9`) allowing the user to click any character to inspect/draw it + **Interactive Stylus Capture Canvas** (`#handwriting-canvas`) with cap/x-height/baseline guide rails, real `pointerdown`/`pointermove`/`pointerup` drawing, velocity/point telemetry, `Clear`, `Save Glyph`, and `Download Printable A4 Sheet (PDF)`.
     - Right pane: **Quality Telemetry Cards** + **Interactive Organic Humanizer Sliders** (`Baseline Wander`, `Slant Drift`, `Spacing Jitter`, `Stroke Wobble`) + **Live Synthesized Sentence Preview Canvas** that updates when sliders move.
   - **3. Calibration Wizard**:
     - Left pane: Full-size **235×235 mm Ender 3 Bed CAD Canvas** with 10mm grid, `(0,0)` home marker, live toolhead crosshair, A5 paper sheet quad, and 5mm-expanded red hatched binder clip keepouts.
     - Right pane: **Interactive XY/Z Jog Pad** (directional buttons `+Y/-Y/-X/+X`, `Home G28`, step sizes `0.1 / 1.0 / 10 mm`, Z micro-jog `+0.05 / -0.05 mm`) + **4-Step Tactile Wizard Cards** + **Measured Geometry Readout Table** (`TL`, `TR`, `BL`, `BR`, skew angle, `Z-touch`, `Z-write`, `Z-lift`) + `Auto-Detect via Camera` button wired to `/api/calibration/camera`.
   - **4. Plot Monitor**:
     - Left pane: Full-viewport **Kinematic Toolpath Canvas** rendering the actual compiled G-code segments (rapid travels in dashed slate, pen-down strokes in crisp cyan/white, live toolhead indicator) + **Interactive Playback Scrubber Bar** (`Play/Pause`, timeline slider `0–100%`, speed `1x/10x/50x`, current stroke counter).
     - Right pane: **6 Tabular-Nums Telemetry Cards** + **Live Marlin Serial G-code Stream Log** (displaying real numbered checksum G-code lines `N1 M104 S0*...` from the compiled job) + **CUPS Virtual Print Spool Queue** wired to `GET /api/jobs`.
   - **5. Settings**:
     - Categorized two-column **Machine & Safety Configuration** (`Envelope & Feedrates`, `Z-Axis & Spring Mount`, `Serial Checksum Protocol`, `Local-First Privacy Audit`) with unit suffixes (`mm`, `mm/min`, `baud`), safety range descriptions, and working `Save Configuration` (`POST /api/settings`) with visual confirmation.

## Acceptance
- `uv run pytest tests/unit/api/test_server.py` passes 100%.
- Headless Playwright verification in `scripts/capture_screenshots.py`:
  - Triggers real document composition (`POST /api/document/compose`), renders > 100 real vector strokes on the Document Studio paper canvas and Plot Monitor toolpath canvas, captures all 5 views at `1440x900`, and asserts 0 console/page errors.
  - All 5 screenshots in `docs/screenshots/ui/` are inspected via `view_file` and verified to have **zero giant empty black voids**, **zero raw unparsed LaTeX `<p>` tags**, **zero Bootstrap blue `#2563eb` slop**, and **zero hardcoded sine waves**.
- Interactive tests prove:
  - Clicking `#btn-compose-doc` updates the vector paper canvas, block tree, and G-code log.
  - Drawing on `#handwriting-canvas` and clicking `#btn-save-profile` calls `/api/profile/glyph` and updates quality metrics.
  - Clicking `#btn-next-step` and `#btn-switch-mode` in Calibration Wizard updates the bed canvas and wizard steps via API.
  - Negative test: Uploading a corrupted PDF or > 50 MB payload to `/api/document/upload` returns HTTP 400/413 with a structured error.

## Anti-shortcut
- Do not leave empty black cards or giant blank margins inside panels.
- Do not render fake HTML text instead of vector strokes on the paper preview.
- Do not draw a hardcoded sine wave in Plot Monitor; render the actual compiled G-code segments.
