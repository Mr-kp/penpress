# P1-1: Core stroke types

## Goal
Immutable, typed primitives all other zones build on: points in millimetres, strokes (polyline/spline with optional per-point pressure/time), paths grouped into pages, affine transforms, bounds, simplification (Ramer-Douglas-Peucker), resampling.

## Deliverables
`src/penpress/core/` + tests in `tests/unit/core/`; JSON (de)serialisation with a versioned schema (`schema_version`).

## Acceptance
- Hypothesis property tests: transforms compose (T2(T1(p)) == (T2.T1)(p) within 1e-9), inverse round-trips, bounds contain all points, RDP never increases max deviation above epsilon, resample preserves endpoints and length within 0.5%.
- JSON round-trip identity on 1000 random pages; loading an unknown schema_version raises a clear error (negative test).
- NaN/inf/empty stroke inputs are rejected with explicit errors (negative tests).
- `mypy --strict` clean; coverage of `core/` >= 95%.

## Anti-shortcut
- No dict-of-lists untyped structures. No float equality in tests without tolerance. No catching broad exceptions.

## Evidence
Test counts, coverage output, a printed example of the JSON schema.
