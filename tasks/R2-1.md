# R2-1: Equations research spike

## Goal
Decide how LaTeX becomes natural handwritten math in the user's style, with correct 2D structure (fractions, roots, scripts, big operators, matrices, cases), plottable and readable.

## Inputs / context to read first
`docs/developer/research/verified-landscape.md` (Equations section), `tests/fixtures/equations.jsonl` (from R0-1; until it exists, create a 40-item interim list under `research/R2-1/`).

## Candidate approaches (seed list)
A. **Layout from a proper TeX layout engine** (KaTeX/MathJax via Node: extract boxes and baselines of every glyph and rule), then **fill each symbol box with strokes**: from a user symbol bank (sample sheet math page) and fall back to a style-adapted single-stroke math font. Rules (fraction bars, radicals, brackets) generated as strokes with wobble.
B. **Symbol Layout Tree -> real stroke samples** from an open online math dataset (CROHME / MathWriting) as style-neutral fallback; adapt to user via slant/width/size affine + jitter.
C. **Generative stroke model** conditioned on LaTeX (research; check feasibility on CPU and licences).
D. **Cloud LLM drawing** (opt-in prototype to measure only).

Hard problems to solve with evidence: stretchy symbols (large brackets, integrals, radicals over wide content), sub/superscript sizing, matrix alignment, baseline wobble that does not break structure, symbols the user never wrote (fallback quality).

## Deliverables
1. `docs/developer/research/R2-1.md`: verified licences (**MathWriting dataset licence must be read from its dataset page, quoted, with date**), what ran, what broke.
2. `research/R2-1/` prototype: LaTeX string -> strokes (JSON, mm) for approach A at least, plus one other approach prototyped to a measurable level.
3. Round-trip benchmark: render strokes to image -> `pix2tex` / `pix2text` -> LaTeX -> normalised-equality and edit-distance scoring.
4. ADR `docs/developer/adr/0002-equations.md`.
5. Symbol coverage table: which symbols come from the user's bank, which from fallback, and the sample-sheet extension (what math the user is asked to write).

## Metrics
| Metric | Target |
|---|---|
| Round-trip exact match after normalisation, difficulty-1 equations | >= 90% |
| Round-trip exact match, difficulty-2 | >= 75% |
| Round-trip exact match, difficulty-3 | >= 50% (report honestly) |
| Structure correctness (human-readable audit of 30 random renders, written in the evidence file) | no misplaced scripts/fraction bars in >= 90% |
| Stroke plottability | no NaN, no zero-length, bounded curvature; pen lifts per symbol <= 3 |
| Style adaptation | symbols rendered from the user bank visibly match the user's slant/width (quantified like R1) |
| Speed on T0 | <= 2 s per equation |

## Acceptance
- Reviewer reproduces the round-trip table within +-5% from the README commands.
- All 120+ corpus equations processed; failures listed with reasons (parser errors, unsupported constructs).
- ADR accepted with decision, numbers, fallback, and list of dependencies with licence verdicts.
- Contact sheet of >= 24 rendered equations across all categories, **opened and described**, flaws included.
- Documented fallback chain: user symbol -> adapted stroke font -> typeset stroke font, and when each triggers.

## Anti-shortcut
- Do not hand-write strokes for the benchmark equations.
- Do not evaluate on equations that appear in the symbol bank sheet.
- Do not swap the metric if it looks bad; report it and propose improvements.
- Do not rely on the cloud option for the numbers in the decision.
